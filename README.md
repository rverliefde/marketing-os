# ClickSend marketing brand resources

This folder contains ClickSend's core brand and content guidelines in Markdown format. These files are the source of truth for all marketing copy and are used to power the ClickSend Content Editor tool.

---

## Files

| File | Description |
|------|-------------|
| `clicksend-tov-guidelines.md` | Full tone of voice guidelines — pillars, writing rules, before/afters, grammar rules |
| `content-creation-checklist.md` | Pre-submission checklist for all content types |
| `brand-guidelines.md` | Colour palette, typography, logo usage rules |
| `blog-article-template.md` | Structure and writing reminders for blog articles |
| `customer-story-template.md` | Structure and writing tips for customer case studies |
| `customer-service-email-template.md` | Email structure, Johnson box usage, writing reminders |
| `video-script-template.md` | Two-column script format and writing tips for video |

---

## How to update these files

1. Edit the relevant `.md` file directly in GitHub
2. Submit a pull request with your changes and a brief description
3. Once merged, notify the team so the Content Editor tool can be updated to reflect the new guidelines

## Our brand in one sentence

> Empathetic. Smart. Bold. A little weird. — Never corporate, condescending, over-complicated or cringe.
