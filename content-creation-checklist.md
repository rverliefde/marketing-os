# Content creation checklist

Use this checklist before submitting any content for review. Complete every applicable section.

---

## Basic checks

- [ ] Spell check run
- [ ] Headings use sentence case (first word + proper nouns capitalised only)
- [ ] British English spelling throughout (colour, organisation, specialise, etc.)
- [ ] No Oxford comma
- [ ] Correct capitalisation:
  - **ClickSend** — capital C, capital S, no space
  - **eCommerce**, **SMS**, **MMS**, **RCS** — capitalised
  - Other products lowercase: direct mail, email, SMS marketing

---

## Readability checks

- [ ] Avoid referencing our mail product as "post" (confusing for American audiences)
- [ ] Would you want to read this?
- [ ] Is the headline interesting? ([Test it here](https://headlines.coschedule.com/headlines/))
- [ ] Does the content have a logical flow?
- [ ] Are we repeating ourselves anywhere?
- [ ] Does it feel like the author is trying to reach a word count?
- [ ] Is the benefit to the reader clear?
- [ ] Run through a readability checker (Semrush, Grammarly, Hemingway, etc.)

---

## SEO checks

- [ ] URL slug is optimised
- [ ] Appropriate category chosen (one only)
- [ ] A handful of relevant tags added
- [ ] Meta description present and includes the relevant keyword
- [ ] Alt tags added to all images describing the image
- [ ] Heading hierarchy is correct: H3 nested under H2, which is under H1. Only one H1 per page.
- [ ] Keyword density: 2–2.5% of word count. Above that may feel stuffy — use synonyms where possible (without cannibalising another keyword)
- [ ] Internal links have relevant anchor text
- [ ] External links open in a new tab. Add `no-follow` where necessary.

---

## Product checks

- [ ] Are we correctly describing how our product works? (160 characters, inbound rules, country-specific regulation, TFN/consent/opt-in, etc.)
- [ ] Do any referenced integrations behave as described?
