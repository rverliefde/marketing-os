# ClickSend Blog Post Examples — Reference Patterns

These files break down the structure, tone, and formatting patterns of existing ClickSend blog posts, intended as reference material for tailoring the Marketing OS content-generation tool. Each file summarizes the *pattern*, not a verbatim copy of the original post.

| File | Post type | Best used as a template for |
|---|---|---|
| `example-mcp-server-guide.md` | Explainer / how-to | New feature or technical concept explainers |
| `example-sms-health-tech.md` | Industry positioning | Vertical-specific "why choose us" content |
| `example-pulsemedica-case-study.md` | Customer case study | Testimonials, social proof, success stories |
| `example-acma-sender-id-register.md` | Regulatory/news | Compliance updates, policy announcements |
| `example-email-migration-guide.md` | Migration/transition guide | Sunset announcements, cross-sell-via-help content |
